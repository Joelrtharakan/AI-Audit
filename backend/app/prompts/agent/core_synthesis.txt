  finding/evidence directly states one (e.g. "the check was missed"). If CAUSAL CONTEXT above already

  plausibly supports one -- not an action item, not fabricated if nothing supports it.
Layer 4/5 ROOT CAUSE: WHY the established mechanism occurred. This is a SEPARATE, DEEPER question
